# ひらがな単語並べ替え - 学習サイト

子どもが楽しく日本語を学べるインタラクティブな学習サイトです。

## 📚 プロジェクト概要

このサイトは、出題者が選んだひらがな（またはカタカナ）を解答者が並べ替えて単語を完成させるゲーム型学習ツールです。

### ✨ 主な特徴

- **五十音表インターフェース**：直感的に文字を選択できる
- **濁点・半濁点対応**：゛゜ボタンで複雑な文字も選択可能
- **小文字対応**：拗音や小さい「ぁ」「ぃ」なども選択可能
- **カタカナ対応**：ひらがなとカタカナの両方に対応
- **ドラッグ&ドロップ**：カードを自由に配置して答える
- **あたたかいデザイン**：子どもたちが親しみやすい丸みを帯びたデザイン

## 🎮 使い方

### 出題者側

1. `select.html` を開く
2. 五十音表から文字を選択（例：「り」→「ん」→「こ」）
3. 濁点ボタンなどで特殊文字を追加
4. 確認画面で間違いがないか確認
5. 「問題を出す」ボタンをクリック

### 解答者側

1. 出題画面に表��されたバラバラなカードを見る
2. カードをドラッグして正しい順番に並べ替え（または頭で考える）
3. 「答え」ボタンをクリックして正解を確認
4. 画面をタッチして次の問題へ
